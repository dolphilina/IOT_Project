# Greenhouse SCADA — IoT-теплица на ESP32

Веб-интерфейс SCADA-системы для мониторинга и управления умной теплицей на базе **ESP32 DevKitC**, спроектированной в Cirkit Designer.

🌐 **Рабочая ссылка (GitHub Pages):** https://dolphilina.github.io/IOT_Project/

---

## Возможности системы

- **База растений на главном экране (до 5 штук):** динамические SVG-иллюстрации каждого растения в зависимости от его состояния здоровья (`Здорово`, `Требует внимания`, `Болеет`, `Критично`), отображаемые рядом с текущими параметрами микроклимата.
- **Мониторинг всех 5 датчиков в реальном времени:** температура воздуха, влажность воздуха, влажность почвы, уровень воды в баке и освещённость + виртуальное зеркало физического OLED-экрана 128×64.
- **Графики телеметрии во времени:** отдельная вкладка с 5 интерактивными графиками (Chart.js), фильтрами интервала (`5 мин`, `30 мин`, `Всё время`), статистикой Min/Avg/Max и экспортом в CSV.
- **ИИ-диагностика по фото:** отдельная вкладка для загрузки фотографии растения с оценкой состояния через **Google Gemini Vision API** (или локальный цветовой демо-анализатор без ключа). Результаты сохраняются в карточку растения на главном экране.
- **Два режима управления:**
  - **Автоматический** — гистерезисное управление 5 MOSFET-каналами по редактируемым уставкам и с защитой от сухого хода.
  - **Ручной** — индивидуальные тумблеры на каждый модуль и кнопка аварийного отключения.
- **Подключение к ESP32 через MQTT (WSS)** + встроенный физический симулятор теплицы для тестирования без железа.

## Карта пинов ESP32 (по схеме Cirkit Designer)

| Модуль / Датчик | Назначение | Пин ESP32 |
|---|---|---|
| **DHT11** | Температура и влажность воздуха | `GPIO 4` |
| **Capacitive Soil Moisture v1.2** | Влажность почвы | `GPIO 34` (ADC) |
| **Water Level Sensor** | Уровень воды (сигнал / питание) | `GPIO 35` / `GPIO 27` |
| **Фоторезистор LDR** | Освещённость | `GPIO 32` (ADC) |
| **OLED I2C 0.96"** | Дисплей (`SCK` / `SDA`) | `GPIO 22` / `RX (GPIO 3)` |
| **MOSFET #1 · Mini Pump** | Насос полива | `GPIO 18` |
| **MOSFET #2 · Heating Pad** | Нагревательный коврик | `GPIO 19` |
| **MOSFET #3 · Ultrasonic Mist** | Ультразвуковой увлажнитель | `GPIO 33` |
| **MOSFET #4 · LED Strip** | Фитолампа | `GPIO 25` |
| **MOSFET #5 · 5V DC Fan** | Вентилятор обдува | `GPIO 26` |

## Протокол MQTT для прошивки ESP32

По умолчанию используется WebSocket-брокер (`wss://broker.emqx.io:8084/mqtt`) и префикс `dolphilina/iot_greenhouse`.

- **ESP32 → Сайт (`<prefix>/telemetry`)**:
  ```json
  {"airTemp":24.2,"airHumidity":61,"soilMoisture":44,"waterLevel":78,"lightLevel":65}
  ```
- **Сайт → ESP32 (`<prefix>/control`, `retain: true`)**:
  ```json
  {"mode":"auto","actuators":{"pump":false,"heater":false,"humidifier":false,"light":true,"fan":false}}
  ```
- **Статус устройства (`<prefix>/status`)**: `online` или `offline`.
